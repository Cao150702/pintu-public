# 拼途 Pintu

> 找回曾经的那个未来。

**拼途** 是一款竖屏几何切拼叙事体验。用指尖切割、旋转、拼接悬浮的几何材料，填平道路上的坑洞，陪伴主角完成五段旅程。

---

## 玩法

画一条直线切开材料，拖动碎片拼入目标形状。碰撞正确时会自动吸附。

- 🔪 自由直线切割——任意方向，一刀两断
- 🖐 拖拽 + 旋转——选中拼块后拖动圆环旋转
- 🧲 自动吸附——对齐边缘时自动归位
- ↩️ 撤销 + 长按重置——不怕切错
- 🎵 原创音效与生成音乐——随旅程推进层层叠加

## 五关叙事

| 关 | 材料 | 目标 | 寓意 |
|---|------|------|------|
| 1 | 不规则四边形 | 矩形 | 起步 |
| 2 | 两个小正方形 | 一个大正方形 | 配合 |
| 3 | 十字形 | 正方形 | 打破惯性 |
| 4 | 正方形 | 平行四边形 | 视角转换 |
| 5 | 正方形（都德尼剖分） | 正三角形 | 蜕变 |

## 技术

- 零依赖：纯 HTML / CSS / JavaScript，无框架、无 CDN、无构建工具
- 离线完整运行：不联网、不收集数据、不调用外部 API
- 适配移动竖屏：触摸优先，安全区适配，iOS Safari 13.4+ / Android WebView 119+
- Canvas 渲染 + DOM 弹层混合架构

## 体验

用手机竖屏打开即可。桌面浏览器建议调为 9:16 窗口比例。
